# Sponsors

Thank you for supporting android-security-awesome.

This project is a curated collection of Android security resources, tools, and references. Keeping it current, accurate, and easy to navigate takes time and ongoing maintenance. Your support helps maintain the repository, improve quality, and keep the list useful for researchers, developers, and security professionals.

## Support the project

- GitHub Sponsors: [@ashishb](https://github.com/sponsors/ashishb)
- Open Collective: [ashishb](https://opencollective.com/ashishb)

## Why support?

- Keep the repository updated as the ecosystem changes
- Maintain and review links and contributions
- Improve project quality and discoverability
- Help sustain the work behind the curated resource list

## Sponsorship options

Contributions of any size are appreciated. If you are a company or organization, sponsorship is a great way to support the Android security community and help ensure high-quality open-source research resources remain accessible.

If you’d like to support the project in another way, feel free to reach out through the repository maintainers or the linked sponsor profiles.
